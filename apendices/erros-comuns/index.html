    Erros comuns do Python¶

    A mensagem de erro do Python é boa: ela quase sempre diz o que aconteceu e em que linha. Este apêndice traduz as que mais aparecem no curso. Todas foram reproduzidas de verdade — a mensagem aqui é a que o interpretador imprime.

    Leia de baixo para cima

    Um Traceback mostra o caminho até o erro. A última linha diz o tipo e a descrição; a linha imediatamente acima dela mostra o código que falhou. Comece por aí.

    NameError¶

    NameError: name 'potencia_dmb' is not defined. Did you mean: 'potencia_dbm'?

    Um nome que o Python não conhece. Três causas, nesta ordem de probabilidade: erro de digitação (o Python até sugere o certo), uso da variável antes de criá-la, ou — no Colab — a célula que define o nome ainda não foi executada.

    TypeError¶

    TypeError: can only concatenate str (not "int") to str

    Somar texto com número. Converta: int(texto) + 4, ou texto + str(numero).

    TypeError: unsupported operand type(s) for +: 'int' and 'str'

    O mesmo problema do outro lado: os valores da lista vieram de um arquivo e ainda são texto. Converta com float(...) ao ler.

    TypeError: unsupported operand type(s) for +: 'NoneType' and 'int'

    Você usou o retorno de uma função que não tem return. Ela calculou e jogou o resultado fora.

    TypeError: margem() missing 1 required positional argument: 'sensibilidade'

    Faltou um argumento na chamada. A mensagem diz o nome do que faltou.

    TypeError: 'str' object does not support item assignment

    Tentativa de alterar uma string no lugar (s[0] = "X"). String é imutável: monte outra.

    IndexError¶

    IndexError: list index out of range

    Índice além do fim. Numa lista de 4 itens, os índices válidos vão de 0 a 3. Depois de um split, costuma significar que a linha não tinha todos os campos que o código supunha — linha em branco no fim do arquivo é o suspeito número um.

    KeyError¶

    KeyError: 'OLT-CENTRO-01'

    A chave não existe no dicionário. Use dicionario.get(chave, padrao) quando a ausência for normal, e if chave in dicionario quando ela for um caso a tratar.

    ValueError¶

    ValueError: could not convert string to float: '-21,4'

    Em Python, o separador decimal é o ponto. Dado que veio de planilha em português costuma vir com vírgula: texto.replace(",", ".") antes de converter.

    ValueError: invalid literal for int() with base 10: '21.4'

    int("21.4") não funciona: int não aceita a parte decimal em texto. Use int(float("21.4")) se for isso mesmo que você quer.

    ZeroDivisionError¶

    ZeroDivisionError: division by zero

    Quase sempre é a média de uma lista vazia. Trate a lista vazia antes de dividir — e lembre que ela chega vazia no dia em que a coleta falha.

    IndentationError e SyntaxError¶

    IndentationError: unexpected indent

    Espaço sobrando no começo da linha. Em Python a indentação é sintaxe.

    IndentationError: expected an indented block after function definition

    O corpo da função não está recuado.

    SyntaxError: invalid syntax

    Genérico, mas o Python aponta a posição. As causas mais comuns: faltou o : no fim do if/for/def, ou faltou fechar um parêntese na linha anterior — por isso o erro às vezes aparece uma linha depois de onde está o problema.

    AttributeError¶

    AttributeError: 'list' object has no attribute 'upper'

    Método aplicado ao tipo errado. Em geral é o resultado de um split (que é lista) recebendo um método de string.

    Erros que não dão mensagem¶

    Estes são os perigosos, porque o programa roda e entrega o resultado errado:

    Sintoma Causa
    a lista ordenada virou None lista.sort() devolve None; use sorted(lista)
    o acumulador terminou valendo o último item ele foi criado dentro do laço
    o máximo deu 0 numa lista de dBm o candidato começou em zero, e todos os valores são negativos
    a lista do programa principal mudou sozinha uma função alterou a lista que recebeu
    o .strip() "não fez nada" o resultado não foi guardado
    o teste falha com dois valores que parecem iguais falta arredondar: 0.1 + 0.2 não é exatamente 0.3
