    Terminadas as dezesseis semanas, o que estudar agora depende de para onde você quer ir. Três caminhos, todos partindo do que este curso deixou pronto.

    Recursos de Python que ficaram de fora¶

    Este curso escolheu, em vários pontos, a forma longa e explícita em vez da curta. Não foi por ela ser melhor: foi porque a longa é a que você consegue escrever, ler e depurar sozinho enquanto o assunto ainda é novo.

    As formas curtas existem, são muito usadas, e você vai encontrá-las em qualquer código profissional — inclusive no que um assistente de IA te devolver. Esta seção existe para você reconhecê-las, e para tê-las à mão quando quiser passar a usá-las.

    Compreensões¶

    A construção mais comum de todas. Ela escreve numa linha o laço de transformação e o de filtro da Unidade 1:

    # Compreensoes: a forma curta dos lacos que o curso ensinou.
potencias = [-21.4, -19.8, -27.0, -25.1]
nomes = ["OLT-A", "ONU-B", "OLT-C", "ONU-D"]

# TRANSFORMACAO -- o laco do curso...
com_margem = []
for p in potencias:
    com_margem.append(round(p - 3, 2))
print(com_margem)

# ...e a compreensao equivalente.
print([round(p - 3, 2) for p in potencias])

# FILTRO -- com o if no fim.
print([p for p in potencias if p < -25])
print([n for n in nomes if n.startswith("ONU")])

# Compreensao de DICIONARIO.
print({n: p for n, p in zip(nomes, potencias)})

# Compreensao de CONJUNTO.
print(sorted({n.split("-")[0] for n in nomes}))

    A leitura é na ordem: "o resultado, para cada item da coleção, se a condição".

    [round(p - 3, 2)   for p in potencias   if p < -25]
#  o que guardar    de onde vem          quando guardar

    Colchetes produzem lista, {chave: valor for ...} produz dicionário e {item for ...} produz conjunto.

    Uma linha não é um prêmio

    Compreensão é ótima para uma transformação ou um filtro simples. Quando aparece um if/else dentro, dois for aninhados e uma chamada de função no meio, o laço de sempre é mais legível — e legível é o critério. Ninguém ganha nada por caber numa linha.

    Os outros atalhos, lado a lado¶

    # Cada bloco mostra a forma que o curso ensinou e, logo abaixo, o atalho
# equivalente. As duas fazem exatamente a mesma coisa.
from collections import Counter, defaultdict
import csv

linhas = [
    "2026-03-02 14:03:17 CRITICAL OLT-CENTRO-01 perda de sinal",
    "2026-03-02 09:00:00 INFO SWITCH-NORTE-02 porta ativada",
    "2026-03-02 10:02:55 CRITICAL OLT-CENTRO-01 temperatura alta",
]
nomes = []
for linha in linhas:
    nomes.append(linha.split()[3])

# ---- agrupar: o if do curso ----
grupos = {}
for nome in nomes:
    if nome not in grupos:
        grupos[nome] = []
    grupos[nome].append(1)
print(grupos)

# ---- agrupar: setdefault ----
atalho = {}
for nome in nomes:
    atalho.setdefault(nome, []).append(1)
print(atalho)

# ---- agrupar: defaultdict ----
outro = defaultdict(list)
for nome in nomes:
    outro[nome].append(1)
print(dict(outro))

# ---- contar: o get do curso ----
contagem = {}
for nome in nomes:
    contagem[nome] = contagem.get(nome, 0) + 1
print(contagem)

# ---- contar: Counter ----
print(dict(Counter(nomes)))

# ---- o maior valor: o laco do curso ----
campeao = None
for nome, quantos in contagem.items():
    if campeao is None or quantos > contagem[campeao]:
        campeao = nome
print(campeao)

# ---- o maior valor: max com key ----
print(max(contagem, key=contagem.get))

# ---- funcao de ordenacao: def do curso ----
def pelo_valor(par):
    return par[1]

print(sorted(contagem.items(), key=pelo_valor, reverse=True))

# ---- funcao de ordenacao: lambda ----
print(sorted(contagem.items(), key=lambda par: par[1], reverse=True))

    Repare que cada par de blocos imprime exatamente a mesma coisa. Counter e defaultdict vêm do módulo collections da biblioteca padrão, e lambda é uma função sem nome, escrita na própria linha em que é usada.

    E mais duas, da leitura de arquivos¶

    csv.reader devolve cada linha como lista em vez de dicionário, e aí o cabeçalho volta como dado — é preciso descartá-lo com next(leitor) antes do laço. O DictReader que o curso usa faz isso sozinho.

    O try também aceita mais duas cláusulas: else, que roda quando não houve erro, e finally, que roda sempre — útil para liberar um recurso aconteça o que acontecer.

    1. Automação de redes¶

    É a continuação direta da Unidade 7 e a habilidade mais procurada em operadora e integradora.

    • Netmiko e NAPALM para falar com equipamentos de vários fabricantes;
    • Nornir para rodar tarefas em paralelo sobre um inventário;
    • Ansible para descrever a configuração desejada em vez de programá-la passo a passo;
    • pyATS/Genie ou TextFSM para transformar a saída de um comando em dados estruturados.

    Monte um laboratório com GNS3 ou Containerlab e automatize uma topologia de verdade. É isso que se mostra numa entrevista.

    2. Dados e observabilidade¶

    Se o que te interessou foi a Unidade 6:

    • pandas a fundo, e depois Polars para volumes grandes;
    • SQL — a maior parte dos dados de operação mora num banco;
    • Grafana e Prometheus, que é onde o KPI que você calculou vira painel;
    • estatística aplicada: percentis, sazonalidade, detecção de anomalia.

    3. Sinais e rádio¶

    Este curso deixou o lado de DSP de fora, mas as ferramentas são as mesmas:

    • NumPy e SciPy para amostragem, FFT e filtros;
    • PySDR como material de estudo;
    • GNU Radio com um dongle RTL-SDR, que custa pouco e transforma a teoria de modulação em algo que você vê na tela.

    Em qualquer um dos caminhos¶

    • Git e GitHub. Saber versionar não é opcional em nenhum dos três.
    • Ambientes virtuais e pip, para o dia em que o projeto sair do Colab.
    • Escrever testes. Comece com pytest, que é o assert das listas com relatório melhor.
    • Ler código dos outros. Escolha uma biblioteca pequena que você usa e leia o código dela inteiro. É o exercício que mais ensina depois de um curso introdutório.

    E o mais importante: escolha um problema chato do seu dia e automatize. Um script que você usa toda semana ensina mais do que dez tutoriais.
