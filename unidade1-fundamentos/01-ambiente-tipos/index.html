    1. O ambiente, os tipos e o primeiro script¶

    Você já programou antes: sabe o que é uma variável, um if, um laço e uma função. Este capítulo não vai reensinar isso. Ele vai fazer três coisas: colocar você para rodar Python sem instalar nada, mostrar como o Python trata os tipos (que é onde ele se parece menos com o que você viu), e traduzir esse começo para as contas que aparecem num projeto de enlace.

    Onde o código roda¶

    A trilha principal do curso é o Google Colab: um caderno que roda no navegador, com Python já instalado e com as bibliotecas de cálculo e de gráficos prontas. Você escreve o código numa célula, aperta Shift+Enter, e o resultado aparece embaixo. Veja o passo a passo em Ambiente → Google Colab.

    Um caderno tem uma armadilha que vale conhecer desde já: as células guardam o que foi executado, na ordem em que você executou, não na ordem em que aparecem na tela. Se algo ficar estranho, use Ambiente de execução → Reiniciar e executar tudo. Isso resolve a maioria dos mistérios.

    O primeiro script¶

    # Primeiro script: potência medida numa ONU.
potencia_dbm = -21.4
site = "OLT-CENTRO-01"

print(site)
print(potencia_dbm)
print("potencia:", potencia_dbm, "dBm")
print(f"{site} esta em {potencia_dbm} dBm")

    OLT-CENTRO-01
-21.4
potencia: -21.4 dBm
OLT-CENTRO-01 esta em -21.4 dBm

    Três coisas para reparar:

    • não existe declaração de tipo. potencia_dbm = -21.4 cria a variável e já diz que ela é um número com casas decimais — o tipo vem do valor atribuído;
    • não existe ponto e vírgula, e o bloco é definido pela indentação. O recuo de quatro espaços é o que marca o que está "dentro" de um if, de um laço ou de uma função. Ele não é estilo: é sintaxe, e errá-lo é erro de programa;
    • print aceita vários valores, separando-os por espaço automaticamente.

    A última linha usa uma f-string: a letra f antes das aspas libera o uso de { } dentro do texto para encaixar o valor de uma variável. É o jeito padrão de montar texto em Python, e você vai usá-lo o curso inteiro.

    Os tipos que você vai encontrar¶

    # Os quatro tipos que resolvem quase tudo no comeco.
quantidade = 12            # int
potencia = -21.4           # float
site = "OLT-CENTRO-01"     # str
no_ar = True               # bool

print(type(quantidade))
print(type(potencia))
print(type(site))
print(type(no_ar))

# Conversao entre tipos: o dado que vem de um arquivo ou de um equipamento
# sempre chega como texto.
lido = "-21.4"
print(float(lido) + 1)
print(int("42") * 2)
print(str(-21.4) + " dBm")

    <class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
-20.4
84
-21.4 dBm

    int, float, str e bool cobrem quase tudo no começo. O que interessa aqui é a parte de baixo do exemplo: todo dado que chega de fora do programa chega como texto. A leitura de uma porta óptica, o campo de um CSV, a resposta de um equipamento — tudo é str até alguém converter.

    O erro número um de quem está começando

    # O valor lido de um arquivo chega como texto. Somar sem converter nao funciona.
lido = "3"
print(lido + 4)

    TypeError: can only concatenate str (not "int") to str

    A mensagem é literal: o Python só concatena str com str. Ele não adivinha que você queria somar. Converta antes: int(lido) + 4.

    Há um segundo erro tão comum quanto, e que só aparece quando a linha roda:

    # Um nome digitado errado so aparece quando a linha roda.
potencia_dbm = -21.4
print(potencia_dmb)

    NameError: name 'potencia_dmb' is not defined. Did you mean: 'potencia_dbm'?

    Repare que o Python chega a sugerir o nome certo. Um NameError é quase sempre um nome digitado errado, ou uma célula do caderno que você ainda não executou.

    Contas: as quatro que você vai repetir¶

    # Divisao, divisao inteira, resto e potenciacao.
print(7 / 2)
print(7 // 2)
print(7 % 2)
print(2 ** 10)

# Um arredondamento explicito evita a cauda de casas decimais.
print(10 / 3)
print(round(10 / 3, 2))

# Segundos fora do ar -> HH:MM:SS
total = 3661
print(total // 3600, total % 3600 // 60, total % 60)

    3.5
3
1
1024
3.3333333333333335
3.33
1 1 1
    Operador O que faz Detalhe importante
    / divisão sempre devolve float, mesmo em 4 / 2
    // divisão inteira descarta a parte fracionária
    % resto a dupla // e % resolve hora, minuto e segundo
    ** potenciação 10 ** 3, não pow nem ^

    Repare que / preserva a parte fracionária mesmo entre dois inteiros: 7 / 2 dá 3.5, e não 3. Quando você quer o 3 — quantas fibras inteiras cabem, quantos racks completos, quantas horas fechadas —, peça explicitamente com //. Usar / onde se queria // é o tipo de erro que não aparece: o programa roda e entrega 3.5 slots.

    round(valor, casas) aparece em quase todo exercício deste curso, e por um motivo prático: 10 / 3 tem dezesseis casas decimais que ninguém quer ver num relatório de potência.

    A conta que abre qualquer projeto de telecom¶

    Potência óptica não se mede em miliwatts: mede-se em dBm, a mesma grandeza numa escala logarítmica. A razão é conveniência — em dB, ganhos e perdas ao longo do enlace viram soma e subtração em vez de multiplicação e divisão.

    import math

# mW -> dBm e o caminho de volta.
potencia_mw = 0.001
potencia_dbm = 10 * math.log10(potencia_mw)
print(potencia_dbm)

de_volta = 10 ** (potencia_dbm / 10)
print(de_volta)

# 3 dB a mais e o dobro da potencia -- a conta que todo mundo faz de cabeca.
print(round(10 * math.log10(2), 2))

    -30.0
0.001
3.01

    Guarde o último número: 3 dB é o dobro da potência. Um enlace que perde 3 dB entregou metade do que recebeu. É o tipo de conta que você vai fazer de cabeça depois de algumas semanas, e o Python serve aqui para conferir a intuição, não para substituí-la.

    math é o primeiro módulo que você importa. Um módulo é uma caixa de funções prontas que não vêm carregadas por padrão; import math abre a caixa, e math.log10(...) usa o que tem dentro.

    Escolhendo o nome das variáveis¶

    O padrão de Python é minusculas_com_underscore, e o nome deve dizer a grandeza e a unidade quando houver ambiguidade:

    p = -21.4                  # e daqui a três semanas, o que era "p"?
potencia = -21.4           # melhor
potencia_dbm = -21.4       # o que o material profissional faz

    Isso não é preciosismo de estilo. Confundir mW com dBm é o erro que aparece em relatório de campo, e o nome da variável é a defesa mais barata contra ele.

    Sintoma Causa provável

    NameError: name 'x' is not defined nome digitado errado, ou célula não executada
    IndentationError: unexpected indent espaço sobrando no começo da linha
    resultado com dezesseis casas decimais faltou round(valor, 2)
    ValueError: could not convert string to float float("-21,4") — em Python o separador decimal é o ponto

    Onde isso é usado de verdade¶

    Não há nada de escolar nestas contas: elas são o miolo de um orçamento de enlace (link budget), o cálculo que decide se um enlace óptico ou de rádio fecha antes de alguém subir na torre ou puxar a fibra. Potência de transmissão, ganho de antena, perdas no percurso e sensibilidade do receptor entram todos em dB, justamente porque na escala logarítmica o que seria multiplicação vira soma — o capítulo de link budget do PySDR mostra a conta completa, e ela é feita com as mesmas quatro operações deste capítulo.

    A conversão de unidades é o outro caso. A confusão entre MB e Mb aparece em proposta comercial, em dimensionamento de enlace e na explicação que o técnico dá ao cliente que reclama que "contratou 100 megas e baixa 12 por segundo" — os 12 MB/s estão certos, e são os 100 Mb/s divididos por 8.

    Resumo¶

    • Não se declara tipo; o valor atribuído define o tipo.
    • Bloco é indentação, não chave.
    • Dado que vem de fora chega como texto e precisa ser convertido.
    • / devolve float, // devolve inteiro, % dá o resto, ** eleva.
    • f-string (f"{variavel}") é o jeito de montar texto.
    • import math quando precisar de log10, sqrt e companhia.
