    9. Parsers de texto: o log de três fabricantes¶

    Até aqui todo log do curso tinha o mesmo formato, e linha.split()[2] dava a severidade. A rede de verdade não é assim: ela tem equipamentos de fabricantes diferentes, e cada um escreve o mesmo evento do seu jeito. Juntar esses logs num relatório só é trabalho diário de quem opera uma rede.

    Este capítulo não traz nenhuma ferramenta grande. Ele junta o que você já sabe — métodos de string, dicionários, funções e try/except — numa técnica que resolve o problema: um leitor por formato, todos entregando o mesmo dicionário. Esse leitor tem nome: é um parser.

    Três fabricantes, um alarme¶

    # O mesmo tipo de evento, vindo de tres fabricantes diferentes.
linhas = [
    "2026-03-02 14:03:17 CRITICAL OLT-CENTRO-01 perda de sinal na porta GPON0/1/3",
    "Mar  2 14:05:10 SWITCH-NORTE-02 %LINK-3-UPDOWN: Interface Gi0/12, changed state to down",
    'ts=2026-03-02T14:07:44 host=RADIO-OESTE-01 sev=warn msg="enlace degradado"',
]

# O split()[2] da Unidade 1 pegava a severidade. Agora:
for linha in linhas:
    print(linha.split()[2])

    CRITICAL
14:05:10
sev=warn

    Só a primeira linha deu a severidade. Na segunda, a posição 2 é a hora; na terceira, é o texto sev=warn. Os três formatos:

    Formato Quem usa Como a linha é
    A as OLTs (o formato do curso até aqui) data, hora, severidade, equipamento, mensagem
    B os switches, no estilo do syslog Cisco mês abreviado sem ano, dia, hora, equipamento, %FACILIDADE-SEVERIDADE-CÓDIGO: e mensagem
    C os rádios, no estilo chave=valor ts=, host=, sev= e msg="..." com a mensagem entre aspas

    Os três dizem as mesmas quatro coisas — quando, quão grave, quem e o quê —, com palavras e posições diferentes. O objetivo do capítulo é transformar qualquer uma das três linhas no mesmo dicionário:

    {"momento": "2026-03-02 14:03:17", "severidade": "CRITICAL",
 "equipamento": "OLT-CENTRO-01", "mensagem": "perda de sinal na porta GPON0/1/3"}

    Transformar formatos diferentes numa forma só chama-se normalizar. Depois de normalizado, o log dos três fabricantes vira uma lista de dicionários — e a partir daí é a contagem e o agrupamento do capítulo 5.

    Repare no momento: AAAA-MM-DD HH:MM:SS. É o formato em que a ordem alfabética coincide com a do calendário (capítulo 8), então dá para ordenar alarmes de fabricantes diferentes comparando texto.

    Ferramentas novas para texto¶

    Quatro métodos de string, cada um visto sozinho antes de ser usado.

    partition corta o texto na primeira ocorrência de um separador e devolve três pedaços: o que vem antes, o separador e o que vem depois. É o mesmo que achar a posição com find e fatiar dos dois lados — que é mostrado primeiro, para você ver que não há mágica:

    par = "host=RADIO-OESTE-01"

# O jeito que voce ja sabe: achar a posicao do "=" e fatiar dos dois lados.
posicao = par.find("=")
print(posicao)
print(par[:posicao], par[posicao + 1:])

# partition faz o mesmo numa linha: devolve (antes, separador, depois).
print(par.partition("="))
chave, separador, valor = par.partition("=")
print(chave, valor)

# Corta so na PRIMEIRA ocorrencia -- o resto fica inteiro no "depois".
print("%LINK-3-UPDOWN: Interface Gi0/12, changed state to down".partition(": "))

# Separador ausente: nao da erro, o "depois" vem vazio.
print("-- MARK --".partition("="))
print("-- MARK --".find("="))

    4
host RADIO-OESTE-01
('host', '=', 'RADIO-OESTE-01')
host RADIO-OESTE-01
('%LINK-3-UPDOWN', ': ', 'Interface Gi0/12, changed state to down')
('-- MARK --', '', '')
-1

    Dois detalhes que tornam o partition bom para dado sujo: ele corta uma vez só (o resto da mensagem, com seus : e vírgulas, fica inteiro), e, quando o separador não existe, não dá erro — devolve o texto inteiro no primeiro pedaço e os outros dois vazios. O find, nesse caso, devolve -1.

    split com maxsplit quebra no máximo N vezes. E aqui aparece a diferença entre split() e split(" "), que o formato B expõe por causa dos dois espaços antes do dia:

    linha = "Mar  2 14:05:10 SWITCH-NORTE-02 %LINK-3-UPDOWN: Interface Gi0/12, changed state to down"

# Com " " (um espaco), cada espaco separa -- e os dois espacos antes do "2"
# criam um pedaco vazio.
print(linha.split(" ")[:4])

# Sem argumento, qualquer quantidade de espaco conta como um separador so.
print(linha.split()[:4])

# maxsplit: quebra no maximo N vezes; o resto da linha fica num pedaco so.
campos = linha.split(maxsplit=4)
print(len(campos))
print(campos[4])

    ['Mar', '', '2', '14:05:10']
['Mar', '2', '14:05:10', 'SWITCH-NORTE-02']
5
%LINK-3-UPDOWN: Interface Gi0/12, changed state to down

    split(" ") trata cada espaço como um separador, e dois espaços seguidos deixam um pedaço vazio no meio — o dia foi para a posição 2. split() sem argumento trata qualquer sequência de espaços como um separador só. Para log, use split(). E com maxsplit=4, os quatro primeiros campos saem separados e a mensagem inteira fica no quinto, com os espaços dela intactos.

    startswith, endswith, isdigit e strip com argumento respondem perguntas sobre o texto sem quebrá-lo:

    linha = 'ts=2026-03-02T14:07:44 host=RADIO-OESTE-01 sev=warn msg="enlace degradado"'

# startswith / endswith: o texto comeca (ou termina) com isto?
print(linha.startswith("ts="))
print(linha.endswith('"'))

# isdigit: todos os caracteres sao algarismos? (texto vazio da False)
print("2026".isdigit(), "20a6".isdigit(), "-5".isdigit(), "".isdigit())

# strip com argumento: tira ESSES caracteres das pontas, em vez de espacos.
print('"enlace degradado"'.strip('"'))
print("%LINK-3-UPDOWN".strip("%"))

    True
True
True False False False
enlace degradado
LINK-3-UPDOWN

    Repare que "-5".isdigit() é False: o sinal de menos não é algarismo. E strip('"') tira as aspas das pontas, do mesmo jeito que strip() tira espaços.

    Um formato, uma função¶

    Com as ferramentas na mão, cada formato ganha uma função, e as três devolvem um dicionário com as mesmas quatro chaves. O formato A é o mais simples:

    def le_formato_a(linha):
    """Formato A: 2026-03-02 14:03:17 CRITICAL OLT-CENTRO-01 mensagem..."""
    campos = linha.split(maxsplit=4)
    return {
        "momento": campos[0] + " " + campos[1],
        "severidade": campos[2],
        "equipamento": campos[3],
        "mensagem": campos[4],
    }


alarme = le_formato_a("2026-03-02 14:03:17 CRITICAL OLT-CENTRO-01 perda de sinal na porta GPON0/1/3")
print(alarme["severidade"])
print(alarme["mensagem"])
print(alarme)

    CRITICAL
perda de sinal na porta GPON0/1/3
{'momento': '2026-03-02 14:03:17', 'severidade': 'CRITICAL', 'equipamento': 'OLT-CENTRO-01', 'mensagem': 'perda de sinal na porta GPON0/1/3'}

    O maxsplit=4 resolve o problema da mensagem com espaços, que no capítulo 2 exigia um " ".join(campos[4:]).

    Os formatos B e C precisam de mais uma peça antes.

    Tabelas de tradução¶

    Cada fabricante diz a mesma coisa com outras palavras: o B escreve a severidade como um número de 0 a 7; o C escreve crit, warn, info; o B escreve o mês como Mar. Traduzir é trabalho para um dicionário — o capítulo 5 usado como tabela:

    # Tabelas de traducao: cada fabricante diz a mesma coisa com outras palavras.
SEVERIDADE_POR_NUMERO = {"0": "EMERGENCY", "1": "ALERT", "2": "CRITICAL", "3": "ERROR",
                         "4": "WARNING", "5": "NOTICE", "6": "INFO", "7": "DEBUG"}
SEVERIDADE_C = {"crit": "CRITICAL", "warn": "WARNING", "info": "INFO"}
MESES = {"Jan": 1, "Feb": 2, "Mar": 3, "Apr": 4, "May": 5, "Jun": 6,
         "Jul": 7, "Aug": 8, "Sep": 9, "Oct": 10, "Nov": 11, "Dec": 12}

# O codigo do formato B carrega a severidade como numero, no meio.
codigo = "%LINK-3-UPDOWN"
partes = codigo.strip("%").split("-")
print(partes)
print(SEVERIDADE_POR_NUMERO[partes[1]])

print(SEVERIDADE_C["warn"])

# O mes em texto vira numero -- e o numero vira "03" com o :02d da Unidade 1.
mes = MESES["Mar"]
print(f"2026-{mes:02d}-{2:02d}")

    ['LINK', '3', 'UPDOWN']
ERROR
WARNING
2026-03-02

    As chaves de SEVERIDADE_POR_NUMERO são texto ("3"), e não número: o que sai do split é texto, e assim a consulta é direta, sem conversão. Os nomes em maiúsculas são uma convenção de Python para "tabela fixa, que o programa não altera".

    Com as tabelas, o formato B:

    MESES = {"Jan": 1, "Feb": 2, "Mar": 3, "Apr": 4, "May": 5, "Jun": 6,
         "Jul": 7, "Aug": 8, "Sep": 9, "Oct": 10, "Nov": 11, "Dec": 12}
SEVERIDADE_POR_NUMERO = {"0": "EMERGENCY", "1": "ALERT", "2": "CRITICAL", "3": "ERROR",
                         "4": "WARNING", "5": "NOTICE", "6": "INFO", "7": "DEBUG"}


def le_formato_b(linha, ano=2026):
    """Formato B (estilo Cisco): Mar  2 14:05:10 SWITCH-NORTE-02 %LINK-3-UPDOWN: texto"""
    campos = linha.split(maxsplit=4)
    mes = MESES[campos[0]]
    dia = int(campos[1])
    codigo, _, mensagem = campos[4].partition(": ")
    partes = codigo.strip("%").split("-")
    return {
        "momento": f"{ano}-{mes:02d}-{dia:02d} {campos[2]}",
        "severidade": SEVERIDADE_POR_NUMERO[partes[1]],
        "equipamento": campos[3],
        "mensagem": mensagem,
    }


linha = "Mar  2 14:05:10 SWITCH-NORTE-02 %LINK-3-UPDOWN: Interface Gi0/12, changed state to down"
alarme = le_formato_b(linha)
print(alarme["momento"])
print(alarme["severidade"])
print(alarme)

    2026-03-02 14:05:10
ERROR
{'momento': '2026-03-02 14:05:10', 'severidade': 'ERROR', 'equipamento': 'SWITCH-NORTE-02', 'mensagem': 'Interface Gi0/12, changed state to down'}

    Três coisas acontecem aqui que não aconteciam no A: o ano não vem na linha e entra como parâmetro com valor padrão (capítulo 4); o mês passa pela tabela; e a mensagem é separada do código pelo partition(": "), que corta só no primeiro :.

    E o formato C, em que a mensagem tem espaços dentro das aspas:

    SEVERIDADE_C = {"crit": "CRITICAL", "warn": "WARNING", "info": "INFO"}


def le_formato_c(linha):
    """Formato C (chave=valor): ts=... host=... sev=... msg="texto" """
    # A mensagem tem espacos dentro: separe-a ANTES de quebrar o resto.
    antes, _, mensagem = linha.partition(" msg=")
    campos = {}
    for par in antes.split():
        chave, _, valor = par.partition("=")
        campos[chave] = valor
    return {
        "momento": campos["ts"].replace("T", " "),
        "severidade": SEVERIDADE_C[campos["sev"]],
        "equipamento": campos["host"],
        "mensagem": mensagem.strip('"'),
    }


alarme = le_formato_c('ts=2026-03-02T14:07:44 host=RADIO-OESTE-01 sev=warn msg="enlace degradado"')
print(alarme["momento"])
print(alarme)

    2026-03-02 14:07:44
{'momento': '2026-03-02 14:07:44', 'severidade': 'WARNING', 'equipamento': 'RADIO-OESTE-01', 'mensagem': 'enlace degradado'}

    A ordem importa: primeiro se separa a mensagem com partition(" msg="), depois se quebra o resto em pares. Se o split() viesse primeiro, "enlace degradado" seria cortado em dois pedaços e o segundo não teria =.

    Descobrir o formato e despachar¶

    Falta decidir, para cada linha, qual das três funções chamar. Cada formato tem um sinal que o denuncia logo no começo:

    MESES = {"Jan": 1, "Feb": 2, "Mar": 3, "Apr": 4, "May": 5, "Jun": 6,
         "Jul": 7, "Aug": 8, "Sep": 9, "Oct": 10, "Nov": 11, "Dec": 12}


def detecta_formato(linha):
    """Diz de qual fabricante e a linha: "A", "B", "C" ou None."""
    if linha.startswith("ts="):
        return "C"
    if linha[:3] in MESES and "%" in linha:
        return "B"
    if linha[:4].isdigit() and linha[4:5] == "-":
        return "A"
    return None


linhas = [
    "2026-03-02 14:03:17 CRITICAL OLT-CENTRO-01 perda de sinal na porta GPON0/1/3",
    "Mar  2 14:05:10 SWITCH-NORTE-02 %LINK-3-UPDOWN: Interface Gi0/12, changed state to down",
    'ts=2026-03-02T14:07:44 host=RADIO-OESTE-01 sev=warn msg="enlace degradado"',
    "-- MARK --",
    "",
]
por_formato = {}
for linha in linhas:
    formato = detecta_formato(linha)
    print(formato)
    por_formato[formato] = por_formato.get(formato, 0) + 1
print(por_formato)

{'A': 1, 'B': 1, 'C': 1, None: 2}
    • C começa com ts=;
    • B começa com um mês (linha[:3] é uma chave de MESES) e tem o % do código;
    • A começa com quatro algarismos e um hífen — o ano.

    A ordem dos testes vai do sinal mais específico para o mais genérico. E a função devolve None para o que não reconhece: -- MARK -- (uma linha que alguns servidores de syslog escrevem só para dizer "estou vivo") e a linha vazia.

    Com o formato na mão, uma função le_linha chama o leitor certo com if/elif — é o que se chama despachar. Ela aparece completa na última seção, junto com o tratamento das linhas que nenhum leitor entende.

    Validar sem adivinhar¶

    Parte do trabalho com texto é recusar o que não está no formato, antes que o dado errado entre no relatório. Dois casos de todo dia em rede são o endereço IP e o endereço MAC.

    Um IPv4 são quatro números de 0 a 255 separados por ponto. Cada condição vira uma linha, e a função devolve False na primeira que falhar:

    def ip_valido(texto):
    """Diz se o texto e um IPv4 no formato a.b.c.d, cada parte de 0 a 255."""
    partes = texto.strip().split(".")
    if len(partes) != 4:
        return False
    for parte in partes:
        if not parte.isdigit():
            return False
        if int(parte) > 255:
            return False
    return True


# Os casos de borda sao o teste de verdade de um validador.
print(ip_valido("10.0.3.47"))
print(ip_valido(" 10.0.3.47 "))
print(ip_valido("10.0.3"))
print(ip_valido("10.0.3.256"))
print(ip_valido("10.0.3.-1"))
print(ip_valido("10.0..47"))
print(ip_valido("dez.0.3.47"))

assert ip_valido("255.255.255.255")
assert not ip_valido("256.1.1.1")

    Os casos de teste são a parte mais importante: parte que falta, 256, sinal de menos, parte vazia entre dois pontos, letra. Cada um derruba uma condição diferente. Um validador testado só com "10.0.3.47" não foi testado.

    Um MAC são seis pares de dígitos hexadecimais (0–9 e a–f). O IEEE, que distribui esses endereços, escreve com hífens (AC-DE-48-00-11-22); a maioria dos equipamentos mostra com dois-pontos e em minúsculas. O validador aceita os dois, normalizando antes de conferir:

    HEXADECIMAL = "0123456789abcdef"


def mac_valido(texto):
    """Diz se o texto e um MAC: 6 pares hexadecimais separados por ":" ou "-"."""
    partes = texto.strip().lower().replace("-", ":").split(":")
    if len(partes) != 6:
        return False
    for parte in partes:
        if len(parte) != 2:
            return False
        for caractere in parte:
            if caractere not in HEXADECIMAL:
                return False
    return True


print(mac_valido("AC-DE-48-00-11-22"))    # a forma do IEEE, com hifens
print(mac_valido("ac:de:48:00:11:22"))    # a forma mais comum nos equipamentos
print(mac_valido("ac:de:48:00:11"))       # faltou um par
print(mac_valido("ac:de:48:00:11:2g"))    # g nao e hexadecimal
print(mac_valido("acde.4800.1122"))       # outro formato, que este validador recusa

True

    O último caso é um MAC de verdade — alguns fabricantes o mostram em três grupos de quatro, com pontos —, e este validador o recusa. Recusar é uma decisão legítima, desde que seja escrita: a docstring diz quais formatos a função aceita.

    A linha que não é de ninguém¶

    Um log real sempre traz linhas que nenhum leitor entende: a que não é de formato nenhum, a que foi cortada no meio da gravação, a que tem um campo corrompido. O padrão é o do capítulo 8: a linha ruim é descartada e registrada, e o resto segue.

    # O padrao completo: as pecas das secoes anteriores, juntas. (As funcoes estao
# repetidas aqui para o exemplo rodar sozinho.)
from pathlib import Path

MESES = {"Jan": 1, "Feb": 2, "Mar": 3, "Apr": 4, "May": 5, "Jun": 6,
         "Jul": 7, "Aug": 8, "Sep": 9, "Oct": 10, "Nov": 11, "Dec": 12}
SEVERIDADE_POR_NUMERO = {"0": "EMERGENCY", "1": "ALERT", "2": "CRITICAL", "3": "ERROR",
                         "4": "WARNING", "5": "NOTICE", "6": "INFO", "7": "DEBUG"}
SEVERIDADE_C = {"crit": "CRITICAL", "warn": "WARNING", "info": "INFO"}


def le_formato_a(linha):
    campos = linha.split(maxsplit=4)
    return {"momento": campos[0] + " " + campos[1], "severidade": campos[2],
            "equipamento": campos[3], "mensagem": campos[4]}


def le_formato_b(linha, ano=2026):
    campos = linha.split(maxsplit=4)
    mes = MESES[campos[0]]
    dia = int(campos[1])
    codigo, _, mensagem = campos[4].partition(": ")
    partes = codigo.strip("%").split("-")
    return {"momento": f"{ano}-{mes:02d}-{dia:02d} {campos[2]}",
            "severidade": SEVERIDADE_POR_NUMERO[partes[1]],
            "equipamento": campos[3], "mensagem": mensagem}


def le_formato_c(linha):
    antes, _, mensagem = linha.partition(" msg=")
    campos = {}
    for par in antes.split():
        chave, _, valor = par.partition("=")
        campos[chave] = valor
    return {"momento": campos["ts"].replace("T", " "),
            "severidade": SEVERIDADE_C[campos["sev"]],
            "equipamento": campos["host"], "mensagem": mensagem.strip('"')}


def detecta_formato(linha):
    if linha.startswith("ts="):
        return "C"
    if linha[:3] in MESES and "%" in linha:
        return "B"
    if linha[:4].isdigit() and linha[4:5] == "-":
        return "A"
    return None


def le_linha(linha):
    """Devolve o alarme normalizado, ou None se a linha nao for de ninguem."""
    formato = detecta_formato(linha)
    try:
        if formato == "A":
            return le_formato_a(linha)
        if formato == "B":
            return le_formato_b(linha)
        if formato == "C":
            return le_formato_c(linha)
    except (IndexError, KeyError, ValueError):
        return None      # parecia de um formato, mas veio quebrada
    return None          # nao e de nenhum formato conhecido


por_severidade = {}
descartadas = []
with open(Path("trabalho") / "alarmes_misturados.log", encoding="utf-8") as arquivo:
    for linha in arquivo:
        linha = linha.strip()
        if len(linha) == 0:
            continue
        alarme = le_linha(linha)
        if alarme is None:
            descartadas.append(linha)
            continue
        sev = alarme["severidade"]
        por_severidade[sev] = por_severidade.get(sev, 0) + 1

print(por_severidade)
print(len(descartadas), "descartadas:")
for linha in descartadas:
    print("  ", linha)

    Onde isso é usado de verdade¶

    O formato B imita o das mensagens de sistema do Cisco IOS, documentado como %FACILIDADE-SEVERIDADE-MNEMÔNICO: texto, em que a severidade é um dígito de 0 (emergência) a 7 (depuração). Essa escala de oito níveis é a do próprio protocolo syslog, definida na RFC 5424, seção 6.2.1 — por isso a tabela SEVERIDADE_POR_NUMERO do capítulo vale para qualquer equipamento que fale syslog, não só para um fabricante. O formato C é o estilo chave=valor, conhecido como logfmt, comum em software de rede mais recente.

    Normalizar logs de fontes diferentes num conjunto de campos comum é exatamente o que fazem as plataformas de análise de log e de segurança (SIEM). O Elastic Common Schema, por exemplo, é uma especificação aberta de nomes de campo para que eventos de equipamentos e sistemas diferentes possam ser pesquisados e correlacionados juntos — o mesmo papel do dicionário de quatro chaves deste capítulo, em escala industrial.

    A ideia de um leitor por formato é a da biblioteca Genie Parser, do ecossistema pyATS: milhares de parsers, cada um para um comando num sistema operacional de equipamento, todos entregando a saída como dicionário Python.

    E a forma de escrever MAC com hífens é a recomendada pelo IEEE nas suas diretrizes para identificadores EUI; a dos dois-pontos é a que a maioria dos equipamentos exibe. Um script que compara MACs sem normalizar antes acha que AC-DE-48-00-11-22 e ac:de:48:00:11:22 são equipamentos diferentes.

    Erros comuns deste capítulo¶

    Sintoma Causa provável
    pedaço vazio '' no meio da lista split(" ") numa linha com dois espaços seguidos; use split()
    a mensagem saiu cortada na primeira palavra faltou o maxsplit, ou o split() veio antes do partition(" msg=")
    KeyError com um número entre aspas, como '3' a tabela foi escrita com chaves numéricas (3) e a consulta usa texto ("3")
    ValueError: too many values to unpack desempacotou o resultado de um split que deu mais pedaços que o esperado; use partition quando só há um separador que importa
    o validador aceitou "256.1.1.1" faltou a condição da faixa, ou ela nunca foi testada com o caso de borda
    um fabricante sumiu do relatório as linhas dele caíram todas no descarte; confira a lista de descartadas

    Resumo¶

    • Normalizar é transformar formatos diferentes numa forma só; o parser de cada formato devolve o mesmo dicionário.
    • partition(sep) corta na primeira ocorrência e nunca dá erro por falta do separador.
    • split() sem argumento para log; maxsplit para manter a mensagem inteira.
    • startswith, isdigit e strip(caracteres) perguntam sobre o texto sem quebrá-lo.
    • Diferenças de vocabulário entre fabricantes se resolvem com tabelas de tradução (dicionários).
    • Detecte o formato pelo sinal mais específico, e despache com if/elif.
    • Valide recusando cedo, e teste com os casos de borda.
    • A linha que ninguém entende é descartada e registrada — e o relatório diz quantas foram.
