    11. pandas: os laços que você já escreveu, prontos¶

    Até aqui, toda pergunta sobre um arquivo virou um laço: abrir, converter, pular a linha vazia, acumular, contar, agrupar. Você escreveu esses laços muitas vezes — e por isso está pronto para o pandas, a biblioteca que traz todos eles prontos, testados e rápidos, operando sobre uma tabela inteira de uma vez.

    O capítulo mostra cada operação ao lado do laço que ela substitui. Não é nostalgia: quem sabe o que o laço faz é quem consegue conferir se a linha do pandas deu o número certo.

    💡 Pense assim: da panela para a batedeira

    Uma biblioteca é um conjunto de ferramentas prontas, escritas e testadas por outras pessoas, que se instala e se importa como o math. Quem sabe bater massa na mão entende o que a batedeira faz — e percebe na hora quando ela está batendo errado. Você aprendeu a bater na mão (os laços); o pandas é a batedeira.

    Os dados são um mês de medições de hora em hora de cinco OLTs: medicoes_mes.csv (veja Dados do curso). No Colab, o arquivo se lê direto do site:

    df = pd.read_csv("https://lacouth.github.io/python_telecom-site/dados/medicoes_mes.csv")

    • import pandas as pd é a forma de importar que todo mundo usa — pd é só um apelido curto;
    • pd.read_csv lê o CSV inteiro numa tabela, o DataFrame (por costume, a variável se chama df). As linhas ganham um número à esquerda, o índice;
    • df.shape dá (linhas, colunas): 5 OLTs × 24 horas × 31 dias = 3 720 linhas;
    • df["potencia_dbm"] é uma coluna, que o pandas chama de Series: uma lista de valores com nome e índice.

    💡 Pense assim: a planilha que se programa

    Um DataFrame é uma planilha dentro do Python: linhas numeradas, colunas com nome no cabeçalho, uma célula em cada cruzamento. A diferença é que, em vez de clicar e arrastar fórmulas, você escreve a operação uma vez — e ela vale para a coluna inteira, com três mil ou três milhões de linhas.

    E repare no que não foi preciso fazer: converter com float(). O pandas olha a coluna inteira e percebe que ela tem números.

    O reencontro¶

    A média da potência, das duas formas:

    import csv
import pandas as pd

# O jeito do capitulo 7: DictReader, conversao, acumulador -- e pular o vazio.
soma = 0.0
quantas = 0
with open("trabalho/medicoes_mes.csv", encoding="utf-8", newline="") as arquivo:
    for registro in csv.DictReader(arquivo):
        if registro["potencia_dbm"] == "":        # equipamento fora do ar
            continue
        soma = soma + float(registro["potencia_dbm"])
        quantas = quantas + 1
print(round(soma / quantas, 2))

# O mesmo numero, com pandas: a conversao e o "pular o vazio" ja vem feitos.
df = pd.read_csv("trabalho/medicoes_mes.csv")
print(round(df["potencia_dbm"].mean(), 2))

    -21.91
-21.91

    O mesmo número. O laço precisou de abrir, converter, pular as linhas em que o equipamento estava fora do ar (potência vazia) e dividir; o pandas fez tudo isso em df["potencia_dbm"].mean(). As células vazias viram NaN ("não é um número") na tabela, e as contas do pandas as deixam de fora sozinhas.

    💡 Pense assim: a célula em branco da lista de presença

    Na lista de presença, a célula em branco não quer dizer "zero faltas" nem "zero presenças": quer dizer não anotado. O NaN é isso. Por isso o pandas não o trata como zero numa média — contá-lo como zero puxaria a média para baixo com uma medição que nunca existiu.

    Filtrar¶

    import pandas as pd

df = pd.read_csv("trabalho/medicoes_mes.csv")

# Uma comparacao com a coluna inteira da uma coluna de True/False: a mascara.
fora = df["estado"] == "DOWN"
print(fora.head(3))
print(fora.sum())               # True conta como 1

# A mascara entre colchetes escolhe as linhas -- o padrao filtro.
quedas = df[fora]
print(quedas.head())

# Duas condicoes: & (e) ou | (ou), cada condicao entre parenteses.
sul_ruim = df[(df["enlace"] == "OLT-SUL-03") & (df["potencia_dbm"] < -25)]
print(len(sul_ruim))

    Isto é o padrão filtro, em dois tempos:

    1. df["estado"] == "DOWN" compara a coluna inteira com "DOWN" e devolve uma coluna de True/False — a máscara. Somá-la conta os True;
    2. df[mascara] devolve só as linhas em que a máscara é True.

    💡 Pense assim: o marca-texto

    A máscara é passar o marca-texto nas linhas da planilha que atendem à condição: cada linha fica marcada (True) ou não (False). df[mascara] é recortar e ficar só com as linhas marcadas. Contar as marcadas (somar a máscara) é contar quantas linhas atendem à condição.

    Para juntar condições, usam-se & (e) e | (ou), cada condição entre parênteses. O and e o or de sempre não funcionam aqui — eles comparam um valor com outro, e a máscara é uma coluna inteira:

    import pandas as pd

df = pd.DataFrame({"enlace": ["OLT-SUL-03", "OLT-NORTE-02"], "potencia_dbm": [-26.1, -21.8]})
# "and" compara UM valor com outro; com colunas inteiras, o certo e & com parenteses.
print(df[df["enlace"] == "OLT-SUL-03" and df["potencia_dbm"] < -25])

    ValueError: The truth value of a Series is ambiguous. Use a.empty, a.bool(), a.item(), a.any() or a.all().

    import pandas as pd

df = pd.read_csv("trabalho/medicoes_mes.csv")

# Uma conta com a coluna inteira vira uma coluna nova -- o padrao transformacao.
df["margem_db"] = (df["potencia_dbm"] + 27).round(2)
df["no_ar"] = df["estado"] == "UP"

print(df[["enlace", "potencia_dbm", "margem_db", "no_ar"]].head(3))

    Agrupar¶

    import pandas as pd

df = pd.read_csv("trabalho/medicoes_mes.csv")

# O laco do capitulo 5: quantas horas cada enlace ficou fora do ar.
horas_fora = {}
for enlace, estado in zip(df["enlace"], df["estado"]):
    if estado == "DOWN":
        horas_fora[enlace] = horas_fora.get(enlace, 0) + 1
print(horas_fora)

# A mesma contagem com groupby: filtra, agrupa pelo enlace, conta.
print(df[df["estado"] == "DOWN"].groupby("enlace").size())

# Media por grupo.
print(df.groupby("enlace")["potencia_dbm"].mean().round(2))

# Disponibilidade: a media de uma coluna True/False e a fracao de True.
df["no_ar"] = df["estado"] == "UP"
disponibilidade = (df.groupby("enlace")["no_ar"].mean() * 100).round(3)
print(disponibilidade)

    groupby("enlace") separa a tabela em um pedaço por enlace; o que vem depois diz o que fazer com cada pedaço: .size() conta as linhas, ["potencia_dbm"].mean() tira a média de uma coluna. É o agrupamento do capítulo 5 — o dicionário horas_fora, montado no laço, e a saída do groupby dizem a mesma coisa.

    💡 Pense assim: as pilhas de provas

    Com as provas de todas as turmas misturadas, a coordenadora separa uma pilha por turma (groupby("turma")) e, em cada pilha, tira a média das notas (.mean()) ou conta quantas provas há (.size()). O resultado é uma linha por turma.

    O último bloco é o primeiro KPI do capítulo: a disponibilidade. A coluna no_ar tem True nas horas em serviço, e a média de uma coluna de True/False é a fração de True (cada True conta 1, cada False conta 0). Vezes 100, é a porcentagem do tempo no ar. A OLT-LESTE-04 ficou em 98,925% — oito horas fora num mês de 744.

    📡 Na rede: KPI e disponibilidade

    Um KPI é um número que a operação acompanha sempre, como o painel do carro. A disponibilidade é o mais importante deles: a porcentagem do tempo em que o serviço funcionou. Março tem 744 horas; ficar 8 horas fora dá 98,925%. Parece muito, mas um contrato (SLA) de 99,5% permite só 3,7 horas fora nesse mês — e quem descumpre devolve dinheiro ao cliente. Veja Disponibilidade, SLA e KPI.

    Ordenar e top-N¶

    import pandas as pd

df = pd.read_csv("trabalho/medicoes_mes.csv")

    Datas¶

    import pandas as pd

df = pd.read_csv("trabalho/medicoes_mes.csv")

# O texto vira data de verdade -- o strptime do capitulo 8, na coluna inteira.
df["timestamp"] = pd.to_datetime(df["timestamp"])
df["hora"] = df["timestamp"].dt.hour
df["dia"] = df["timestamp"].dt.day

# Trafego medio de cada hora do dia: o perfil diario da rede.
por_hora = df.groupby("hora")["trafego_mbps"].mean().round(0)
print(por_hora.idxmax(), por_hora.max())
print(por_hora.idxmin(), por_hora.min())

# A potencia da OLT-SUL-03 no primeiro e no ultimo dia do mes.
sul = df[df["enlace"] == "OLT-SUL-03"]
por_dia = sul.groupby("dia")["potencia_dbm"].mean().round(2)
print(por_dia[1], por_dia[31])

    21 574.0
4 69.0
-21.99 -26.47

    pd.to_datetime é o strptime do capítulo 8 aplicado à coluna inteira; depois dele, .dt.hour e .dt.day tiram a hora e o dia de cada linha. Agrupando pela hora, aparece o perfil diário da rede: pico às 21h, vale às 4h — informação que decide, por exemplo, a hora de uma janela de manutenção. E a potência da OLT-SUL-03 caiu quase 4,5 dB ao longo do mês: um enlace se degradando devagar, que nenhum alarme de "fora do ar" pegaria. O próximo capítulo transforma esse número num gráfico.

    📡 Na rede: tráfego e janela de manutenção

    O tráfego é a quantidade de dados que passa pelo enlace por segundo, em Mbps (megabits por segundo). Ele sobe à noite, quando todo mundo chega em casa e assiste a vídeos, e desce de madrugada. A janela de manutenção é o horário combinado para mexer na rede (trocar uma placa, atualizar o sistema): escolhe-se o vale, para afetar o menor número de clientes. Veja Tráfego e utilização.

    O pandas não serve só para CSV. A lista de dicionários que o parser do capítulo 9 devolve vira uma tabela numa linha:

    Onde isso é usado de verdade¶

    O Batfish, ferramenta aberta de análise de configuração de rede usada para validar mudanças antes de aplicá-las, entrega as respostas das suas perguntas como DataFrames do pandas: bf.q.nodeProperties().answer().frame() devolve uma tabela com as propriedades de cada equipamento, e daí em diante filtrar e agrupar é o que este capítulo mostrou.

    KPIs como disponibilidade, perfil de tráfego por hora e degradação de potência são o dia a dia de quem opera rede: a disponibilidade é a base dos contratos de SLA, o perfil diário orienta o dimensionamento e as janelas de manutenção, e a tendência de potência antecipa a visita de campo antes da queda. Em escala, esses números saem de bancos de séries temporais; na análise de um incidente ou num relatório mensal, saem muito frequentemente de um DataFrame num caderno.

    Para quem vem da planilha, a própria documentação do pandas tem uma página de comparação com planilhas, com o equivalente de filtro, tabela dinâmica e PROCV.

    Erros comuns deste capítulo¶

    Sintoma Causa provável
    KeyError: 'potencia' o nome da coluna está errado; confira com df.columns.tolist()
    ValueError: The truth value of a Series is ambiguous usou and/or com colunas; use &/|, cada condição entre parênteses
    o filtro com & deu erro de tipo ou resultado estranho faltaram os parênteses em volta de cada condição
    a coluna de números virou texto alguma célula tem algo que não é número (como "sem leitura"); o pandas lê a coluna inteira como texto
    a média "ignorou" linhas as células vazias viram NaN e ficam fora das contas — confira com count()
    AttributeError: Can only use .dt accessor with datetimelike values faltou o pd.to_datetime na coluna de datas
    a sua saída mostra object onde aqui aparece str, ou o contrário versões diferentes do pandas mostram o tipo texto com nomes diferentes; os valores são os mesmos

    Resumo¶

    • pd.read_csv lê a tabela inteira num DataFrame; uma coluna é uma Series.
    • Comparar uma coluna dá uma máscara; df[mascara] filtra; & e | juntam condições, com parênteses.
    • Conta com a coluna inteira cria coluna nova.
    • mean, min, max, value_counts, count resumem; células vazias (NaN) ficam de fora.
    • groupby(coluna) + o que fazer com cada grupo: .size(), ["x"].mean().
    • A média de uma coluna True/False é uma fração — a disponibilidade.
    • sort_values + head dá o top-N; pd.to_datetime + .dt.hour dá o perfil por hora.
    • Cada linha do pandas é um laço que você já sabe escrever — e é assim que se confere o resultado.
